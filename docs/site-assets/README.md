# Project website

GitHub Pages serves `main:/docs`. German is `index.html`; English is `en.html`.
Both use `site.css`, `language.js` and `site.js`. Edit both HTML files when
changing copy or download links. No build, external fonts, analytics or external
image requests are needed.

## Illustration and content sources

`village-scene.svg` and `icon.svg` are original code-authored vector illustrations.
They use no third-party game assets. Both language versions identify the scene
as an illustration. There were no screenshots in this repository when the
website was prepared.

The village scene is an original SVG illustration, not a Minecraft screenshot. The chart explains default sleep quantity factors [100, 100, 80, 60, 40, 20, 0] for 0 to 6+ missed night-equivalents. It does not simulate Minecraft, stress, offer rounding, restocking or actual trades. The release remains labelled beta; graphical-client and integrated-singleplayer acceptance remain open.

Copy, compatibility and downloads were checked against README documentation
and release `v0.1.0+mc26.2` on 2026-11-11. Keep release status,
scope and compatibility limits aligned when updating either language version.
